# 内容发现器 · Content Finder

在一段文本中，按**分类**找出预置关键词，**高亮**命中位置并提示分类信息，同时给出统计、上下文与风险结论；对有替换建议的命中可**一键修订或脱敏**。既能逐篇细看，也能**批量检测**成百上千条内容。适用于广告文案合规自查、客服工单/舆情分级、敏感信息脱敏、主题词标注等场景。

纯前端应用，所有数据只保存在本机浏览器中，不会上传任何内容。

---

## 功能一览

**内容输入**
- 编辑模式：边输入边高亮（透明输入框叠放在高亮层之上，逐像素对齐）
- 阅读模式：悬停高亮查看「分类 / 级别 / 关键词 / 备注 / 第几处」，点击即聚焦
- 拖拽或导入任意文本文件（文档、代码、配置、日志、HTTP 报文等），自动识别 UTF-8 / UTF-16 / GBK 编码；二进制文件会给出明确提示
- 浏览器导出的 **HAR** 网络记录自动转换为可读的原始 HTTP 报文；HTML 可按设置「提取正文」或「保留源码」
- **代码视图**：等宽字体、不自动换行、显示行号；识别到 HTTP 报文、JSON 或代码时会提示切换
- 内置 5 段示例文本；内容自动保存（关闭页面前也会写入），多个标签页之间自动同步

**关键词与分类**
- 预置 8 个分类、282 个关键词（科技、财经、医疗、地区、正/负面情绪、广告极限用语、个人敏感信息）
- 每个分类可设颜色、级别（提示 / 关注 / 风险）、说明；关键词可附备注（如违规原因）与**替换建议**
- **例外词（误报控制）**：命中完整落在例外词之内就不计入，如「最佳」之于「最佳实践」、「担心」之于「不用担心」；预置 59 个常见例外
- 支持**正则表达式**关键词（手机号、身份证号、邮箱、银行卡号、IP 地址已内置并带脱敏模板），附带**正则语法速查表**、16 个常用模板和即时测试区
- **变体写法识别**：「全 网 第 一」「最★低★价」「微❤信」这类插入空格、符号、表情来规避检测的写法也能命中，提示框中显示还原后的写法
- 阅读模式下**划选文字即可加入词库或设为例外**；「新词发现」可一键收录高频新词
- 词库导入 / 导出 JSON 与 CSV（合并或替换），一键恢复默认；新版预置内容会自动合并进已保存的词库，不覆盖你的修改

**批量检测**
- 一次拖入或选择多个文件，或粘贴多条文本（每行一条 / 空行分段），逐条给出结论、各级别命中数与主要命中
- 默认风险优先排序，可按「存在风险 / 需要关注 / 内容正常 / 未发现命中 / 失败」筛选；点「打开」在编辑器中细看或修订，再一键返回列表
- 导出批量汇总表与命中明细表（CSV，含行号、变体写法、替换建议与上下文）
- 在独立的后台线程中逐条分析，可随时停止；单条超时或读取失败只标记该条，不影响其余

**修订与脱敏**
- 结论卡片直接给出「其中 n 处有替换建议 · 按建议修订」，也可按分类或逐条替换；每次修订都可撤销
- 替换建议支持 `$&` 与正则分组 `$1`、`$2`，例如手机号 `$1****$2` → 138****8000、身份证 `$1********$2` → 110105********002X
- 医疗功效、收益承诺等需要人工判断的用语不给自动替换，保留高亮供逐条处理

**结果分析**
- 综合结论：无命中 / 内容正常 / 需要关注 / 存在风险，并给出各级别命中数
- 分类统计：各分类命中数、占比条、关键词频次；可筛选、聚焦、隐藏
- 命中上下文（KWIC）：逐条列出命中、前后文、行号、违规原因与替换建议，可按风险 / 关注 / 提示筛选，适合作为审核清单
- 新词发现：基于 n-gram 频次统计词库尚未收录的高频词
- 命中分布缩略条：按真实排版位置展示全文命中分布，点击跳转、拖动滚动
- 聚焦导航：聚焦某个关键词或整个分类，其余高亮变淡，F3 逐处跳转

**导出**
- Markdown 报告、可分享的高亮 HTML、CSV 明细表（Excel 可直接打开）、JSON 结构化数据、纯文本摘要

**体验与可靠性**
- 分析在后台 Web Worker 中进行：输入永不卡顿；写错的正则即使陷入「灾难性回溯」也只会被暂停这一条规则，页面照常可用
- 删除关键词、清空内容、修订等操作都提供撤销
- 浅色 / 深色 / 跟随系统主题，正文字号可调；适配手机到宽屏
- 键盘快捷键、无障碍语义（role / aria）、减少动态效果偏好

## 使用说明

1. 在左侧粘贴、输入内容，或把文件拖进窗口（一次拖入多个文件会进入批量检测）。
2. 命中的关键词按分类着色高亮，右侧实时给出结论、分类统计、上下文与新词。
3. 点击高亮或右侧的关键词「聚焦」，再用 <kbd>F3</kbd> / 导航按钮逐处查看。
4. 点击下方图例显示 / 隐藏某个分类，<kbd>Alt</kbd>+点击或双击只看该分类。
5. 遇到误报：在阅读模式下划选包含它的短语，点「设为例外」。
6. 有替换建议时，点结论卡片中的「按建议修订」（或分类上的 ✦、上下文中的「替换」），不满意可撤销。
7. 需要留档时，从「导出」生成报告（含替换建议与例外词排除数）。
8. 要处理多条内容时，点顶栏「批量检测」，粘贴或拖入后按风险逐条处理。

## 匹配规则

| 选项 | 默认 | 说明 |
| --- | --- | --- |
| 区分大小写 | 关 | 关闭时 `gpu`、`Gpu` 都能命中 `GPU` |
| 英文整词匹配 | 开 | 关键词首/尾为英文字母或数字时要求词边界，避免 `AI` 命中 `said`、`OpenAI`；中文不受影响 |
| 全半角统一 | 开 | `ＡＩ`、`１００％` 等全角字符按半角处理，高亮仍显示原文 |
| 识别变体写法 | 开 | 去掉字与字之间的空格、零宽字符、符号与表情后再匹配中文关键词（至少 2 个字），如「全 网 第 一」「最★低★价」；不跨越换行与句读标点（，。、；：！？），原文中最多间隔 4 个干扰字符；英文关键词不参与，避免 `a I` 拼成 `AI` |
| 先解码再匹配 | 开 | URL 编码（`%E6%89%8B`）、`\u` / `\x` 转义、HTML 实体（`&#x624b;`、`&lt;`）先还原再匹配，最多 3 层；高亮落在原文的编码片段上，提示框与上下文中显示解码结果。编码形式的命中不提供自动替换 |
| 重叠处理 | 最长优先 | 「最长优先」：同一位置只保留最左最长的命中；「全部保留」：嵌套、交叉的命中都保留 |

- 每个分类可单独设置「英文整词匹配」与「区分大小写」，未设置时跟随全局。例如代码类分类关闭整词匹配后，`password` 也能命中 `db_password`。
- **例外词**只作用于所属分类：命中完整落在例外词出现的位置之内才排除，部分重叠不排除；例外词与关键词一样做大小写与全半角归一化，对正则规则同样生效。被排除的数量显示在状态栏与分类统计中。
- 同一段文字被多个分类的关键词同时命中时，合并为一处命中，所有分类都会显示在提示框中并分别计数。
- 分类在词库中越靠前，颜色优先级越高（可在词库中上移 / 下移调整）。
- 正则使用 JavaScript 语法，优先以 Unicode 模式编译，并启用多行模式（`^`、`$` 按行匹配）；单条正则最多保留 5000 处命中，超出会在状态栏提示。
- 单次分析超过 2.5 秒视为超时：后台线程被终止，当时正在执行的正则被暂停并在词库中标红，修改该表达式后自动恢复。

## 正则表达式语法速查

应用内的完整速查表在「关键词库 → 新增关键词 → 选择正则 → 语法速查与测试」，也可从「使用说明」打开。其中包括 32 条语法示例、16 个常用模板（手机号、座机、网址、金额、日期、车牌等）和一个即时测试区。测试区与正式分析使用同一套匹配规则，模板可一键填入关键词输入框。表中每个示例都由 `src/data/regexReference.test.ts` 自动验证。

| 语法 | 含义 | 示例 | 在示例文本中命中 |
| --- | --- | --- | --- |
| `.` | 任意一个字符（换行除外） | `第.季度` | 第一季度、第三季度 |
| `\` | 转义，让特殊字符按字面匹配 | `3\.14` | 3.14 |
| `a\|b` | 或 | `退款\|退货` | 退款、退货 |
| `[abc]` | 方括号中的任意一个字符 | `[微企]信` | 微信、企信 |
| `[^abc]` | 不在方括号中的字符 | `第[^一二]名` | 第三名、第五名 |
| `[a-z]` `[0-9]` | 范围内的一个字符 | `[0-5]号` | 3号、5号 |
| `\d` / `\D` | 数字 / 非数字 | `\d+元` | 99元、199元 |
| `\w` | 字母、数字、下划线（不含汉字） | `\w+` | user_01 |
| `\s` / `\S` | 空白 / 非空白 | `微信\s*号` | 微信号、微信 号 |
| `*` `+` `?` | 0 次及以上 / 1 次及以上 / 0 或 1 次 | `https?` | http、https |
| `{n}` `{n,}` `{n,m}` | 恰好 n 次 / 至少 n 次 / n 到 m 次 | `啊{2,3}` | 啊啊、啊啊啊 |
| `*?` `+?` | 非贪婪，尽可能少地匹配 | `【.+?】` | 【限时】、【包邮】 |
| `^` / `$` | 行首 / 行尾（已启用多行模式） | `^\d+\.` | 每行开头的 1.、2. |
| `\b` / `\B` | 单词边界 / 非单词边界（仅英文、数字） | `\bAI\b` | AI（不含 said） |
| `(…)` `(?:…)` | 分组 / 只分组不捕获 | `(?:微信\|QQ)号` | 微信号、QQ号 |
| `\1` | 引用第 1 个分组的内容 | `(.)\1` | 哈哈、天天 |
| `(?=…)` / `(?!…)` | 后面是 / 后面不是 | `\d+(?=元)` | 100元 中的 100 |
| `(?<=…)` / `(?<!…)` | 前面是 / 前面不是 | `(?<!\d)1[3-9]\d{9}` | 不紧跟在数字后的手机号 |
| `\p{Script=Han}` | 一个汉字（Unicode 属性） | `\p{Script=Han}+` | Hello**世界**123**你好** |

使用要点：

- 只写表达式本身，不要加 `/…/` 或 `g`、`i` 标志；大小写由「区分大小写」设置统一控制。
- 开启「全半角统一」后，正则作用在已转为半角的文本上，表达式里的标点请写半角（`!` 而非 `！`），测试区会对此给出提醒。
- 中文场景下要求「前后不挨着数字」时，用 `(?<!\d)…(?!\d)`，不要用 `\b`。

## 词库文件格式

**JSON**（完整格式，导出即为此格式）：

```json
{
  "version": 1,
  "categories": [
    {
      "name": "广告极限用语",
      "color": "#dc2626",
      "level": "danger",
      "description": "《广告法》禁止的绝对化用语",
      "enabled": true,
      "keywords": [
        "最佳",
        { "term": "全网第一", "note": "极限用语，建议改为客观描述", "replacement": "广受好评" },
        { "term": "(?<!\\d)(1[3-9]\\d)\\d{4}(\\d{4})(?!\\d)", "type": "regex", "note": "手机号", "replacement": "$1****$2" }
      ],
      "exclusions": ["最佳实践", "首选项"]
    }
  ]
}
```

也接受简写：`{ "分类名": ["词1", "词2"] }`，或直接是分类数组。缺省字段会自动补全。分类还可带可选的 `wholeWord`、`caseSensitive`（布尔值，覆盖全局设置）；这两项只在 JSON 中保存，CSV 不包含。

**CSV**（可用 Excel 编辑，首行表头可选；类型为「文本」「正则」或「例外」）：

```csv
分类,关键词,类型,备注,替换为
广告极限用语,最好,文本,极限用语,优质
广告极限用语,最佳实践,例外,,
个人敏感信息,"(1[3-9]\d)\d{4}(\d{4})",正则,手机号,$1****$2
```


## 实现要点

- **匹配引擎**：普通关键词用 Aho-Corasick 自动机一次扫描完成，复杂度与关键词数量无关；正则规则单独执行，二者的命中统一做区间合并与重叠消解。约 13 万字、1.2 万处命中的文本分析耗时约 20 ms。
- **等长归一化**：大小写折叠与全半角转换都保持逐字符一一对应，命中位置无需映射即可回到原文。
- **解码与位置映射**：解码会改变长度，所以解码文本的每个码元都记录着它在原文中的来源区间；多层解码时逐层折算。命中在解码文本中查找，再映射回原文高亮。
- **例外词**：例外词另建一台自动机，找出各分类例外词出现的区间后按起点排序并记录前缀最远终点，判断「命中是否被完整覆盖」只需一次二分查找；排除发生在重叠消解之前，被排除的长命中不会再挡住其他分类的短命中。
- **后台分析与超时**：分析运行在内联的 Web Worker 中，执行每条正则前先向主线程汇报。正在运行的正则无法从外部打断，超时后只能终止整个 Worker，再据最后一次汇报定位并暂停那条规则、用新 Worker 重新分析。输入采用「只保留最新」的调度，快速输入时不会积压请求。没有 Worker 的环境（单元测试、个别浏览器禁止 blob Worker）自动退回主线程。
- **变体写法**：去掉干扰字符得到一份「紧凑文本」并记录每个码元在原文中的位置，用同一台自动机再扫描一遍；只保留原文中确实被干扰字符隔开、且跨度不超过上限的命中，再映射回原文高亮。例外词同样在紧凑文本上查找，因此「全 网 第 一 的 补 水 神 器」也能被例外词排除。
- **批量检测**：使用独立于编辑器的后台线程逐条分析，编辑器中的实时分析不受影响；单条超时只会让该条标记为失败。
- **替换建议**：正则规则的建议在命中的原位置以粘连模式（`y`）重新匹配，借助 `d` 标志拿到分组位置再从原文截取，因此前后文断言依旧生效，全角字符原样保留。
- **预置词库升级**：词库记录所基于的预置修订号；加载旧版保存的词库时，为未被改动的预置项补充新写法、备注与替换建议，为预置分类补充例外词与新增关键词，用户删除或修改过的内容保持不变。
- **实时高亮编辑**：`textarea` 与高亮层共享同一套排版参数并同步滚动，大文本输入不卡顿。
- **大文本渲染**：每个高亮片段都是只接收原始类型属性的 memo 组件，聚焦变淡通过容器 class 由 CSS 实现，切换聚焦或分类时只重渲染真正变化的片段。
- **单文件构建**：自定义 Vite 插件把入口脚本和样式内联进 `index.html`，在 `file://` 下也能直接运行。
